# Formatting Rules (German/Austrian Standards)

> **These rules ONLY apply when the project language is German (de-DE / de-AT).**
> If the project is in English or another language, use the respective locale conventions instead.

> Applies to all user-facing text — UI, marketing, emails.

---

## Decimal Separators & Currency

### Rules
- **Comma** as decimal separator: `33,15` not `33.15`
- **€ after the number** with a non-breaking space: `33,15 €`
- **Whole amounts** without cents: `41 €` not `41,00 €`
- **Time references** in consumer-friendly format: `per month` not `/month`

### Examples
```
✅ 33,15 €
✅ 41 € per month
✅ from 5,90 € per person

❌ 33.15 €
❌ €33,15
❌ 41,00 €
❌ 33,15 €/month
```

---

## En Dash

- **En dash (–):** U+2013 for ranges, connections, deductions
- **Hyphen (-):** U+002D only for compound words

### Examples
```
✅ 9–17 h
✅ Vienna–Berlin
✅ – 15 % discount

❌ 9-17 h
❌ -15% discount
```

---

## Percentages

- **Comma** as decimal separator
- **Non-breaking space** before %
- **Discounts** with en dash: `– 5 %`

### Examples
```
✅ 15,5 %
✅ – 10 %
✅ 100 %

❌ 15.5%
❌ 15,5%
❌ -10%
```

---

## Quotation Marks

### German/Austrian
- **Opening:** „ (U+201E)
- **Closing:** “ (U+201C)

### Examples
```
✅ „Welcome to our site.“
❌ "Welcome to our site."
```

---

## Date Format

- **German:** `15. März 2026` or `15.03.2026`
- **Not:** `March 15, 2026` or `2026-03-15` in the UI

---

## Summary

| Element | Correct | Incorrect |
|---------|---------|-----------|
| Decimal | `3,50` | `3.50` |
| Currency | `33,15 €` | `€33.15` |
| Percent | `15 %` | `15%` |
| Range | `9–17 h` | `9-17 h` |
| Quotes | „Text“ | "Text" |
| Date | `15. März` | `March 15` |
