# Claude Code — 120 Ventures Boilerplate

## Changelog

- Every project that originates from this boilerplate MUST have a `CHANGELOG.md` in the repository root
- The changelog documents **user-facing changes** — not purely technical fixes (CI, linting, refactoring) unless they affect the user experience
- Format: grouped by date, newest first, short descriptions
- Update the changelog for every feature, UI change, or important bugfix
- Template:

```markdown
# Changelog

Overview of user-facing changes.

---

## YYYY-MM-DD

### Short title
- Description of the change from the user's perspective
```
